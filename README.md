# プライス道場

商品の価格を予想して、価格感覚を鍛えるブラウザゲームです。ランダムに表示される商品の名前や画像を見て、制限時間内に価格を入力します。

## 主な機能

- 商品の価格を予想し、実際の価格との近さに応じてポイントを獲得。
- ランクに応じて制限時間や獲得ポイントが変化。
- ユーザー登録・ログイン、プレー成績の保存。
- ランキングや総プレー数、平均推測精度の表示。
- スマートフォン向けのレイアウトに対応。

## 使用技術

HTML / CSS / JavaScript / Google スプレッドシート / Google Apps Script

## 起動方法

プロジェクトのフォルダで次のコマンドを実行し、ブラウザで `http://localhost:8000` を開きます。

```sh
python3 -m http.server 8000
```

「ニューゲーム」を押して、予想した価格を入力し「提出」を押してください。

商品・ランキングの取得やログイン、成績保存には、インターネット接続と接続先のGoogle スプレッドシート・Apps Scriptが利用可能であることが必要です。これらのバックエンドのソースは本リポジトリには含まれていません。
